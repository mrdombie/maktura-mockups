Composer redesign — what's in v1 (and why)

Built per spec on 2026-05-24 (#2443). PM brief: "I like the structure of the current beta composer — keep the interaction model. Visual brand pass + missing-elements audit, not a re-architecture." This mockup is Phase 1; live code lands in Phase 2 once PM signs off.

Brand vocabulary applied

  • CompactHeader per #2347 — "Composer" title + draft-saved status + actions (no big PageHero blob).
  • Concept 2 sunset on the AI-agent button + primary Publish / Schedule CTAs.
  • Coral pulse on draft-saved status dot + typing indicator (respects prefers-reduced-motion).
  • Warm-cream surfaces throughout — no bg-white / bg-slate-* / text-slate-*. Editor textarea uses --cream; the persona strip / tools / preview frame all sit on --cream or --warm-white.
  • All Lucide icons via inline SVG. Zero emoji.
  • Cross-fade animation on preview card swap; tab-swap micro-fade on variant tabs.

Per-platform variant editor (multi-platform from day one)

Per feedback_multi_platform_in_every_design.md: every composer view assumes the post has variants for every connected platform. The tabs encode three signals at once:

  • Platform brand dot (LinkedIn navy, X black, IG sunset gradient, TikTok #FE2C55, YT red) — instant scan of which platform the variant is for.
  • Char count vs platform limit from platformMeta() (LinkedIn 3000 · X 280 · IG 2200 · TT 2200 · YT 2200). Tab flips to amber once over, red when materially over.
  • Connection state dot at the right of each tab — green = OAuth connected + publish-ready, amber = draft only (no OAuth), red = OAuth revoked / expired.

Active LinkedIn variant shown in the preview; click any other tab to swap. Per-platform char limits + connection status mirror the runtime values from platformMeta() (#2318) — do not duplicate the registry in this surface.

Persona voice indicator + style-rule chips

  • Compact persona picker — avatar + name + category subtitle. Click opens the persona dropdown.
  • Style-rule chips lifted from the persona's mandatory toolkits + custom rules. SRA-compliant chip is coral-styled to mark a regulated rule (per #1482 regulated-persona safety pattern).
  • Right side shows rule count + sample count so the user can see at a glance how much voice context the AI agent has to work with.

AI agent loop trigger

  • Single sunset-gradient "Run agent" button surfaces the existing Mastra Phase 1 agent chain (Drafter › BrandRule › Rewriter, shipped under PR #2240).
  • The chain order is visible in the button itself — no hidden behaviour.
  • Runs against the current persona + connected signal context (whatever's pinned from Watch / Intelligence feed).

Live preview pane (per-platform chrome)

  • LinkedIn — full LI card with author/role/timestamp, post body, 1200×627 media slot, reaction row.
  • X — tweet card with name/handle + verified glyph + 1200×675 media + timestamp footer.
  • Instagram — square 1:1 card with handle, gradient avatar ring, caption truncation, action row.
  • TikTok — vertical 9:16 frame with caption overlay + side rail + watermark.
  • YouTube — landscape thumbnail + duration badge + channel avatar + title/description block.

Each preview uses authentic-feeling chrome (Segoe/Roboto fonts where appropriate, platform-shaped action rows) so the user sees the post as it'll actually appear — not as a generic preview.

Bottom action bar

Sticky-blur bottom strip with the five canonical actions in priority order: Cancel · Save draft · Send for approval · Schedule · Publish now. Keyboard hints inline on the left (⌘S / ⌘⇧⏎) so power users can stay on the keyboard.

State coverage

The state gallery shows four canonical non-happy-path states:

  • Empty — onboarding nudge points at Watch / Intelligence feed as signal seeds.
  • Over char limit — explicit "X variant 18 over" call with options to trim or LinkedIn-only schedule.
  • Missing media (IG) — Instagram requires media; warn explains the constraint + actionable next step.
  • OAuth disconnected (YT) — reconnect link is one click; drafts can still be saved.

What's deliberately NOT in v1

  • No platform-publishing changes — the Mastra agent loop, the publish-to-LinkedIn worker, OAuth handling all stay (out of scope per spec).
  • No new AI providers — Drafter / BrandRule / Rewriter chain unchanged.
  • No persona model changes — picker reads from existing Persona + PersonaToolkit shape.
  • No bulk-compose / wizard re-introduction — that was removed; batch generation lives in Ask AI command-bar per CLAUDE.md.
  • No A/B variant Lab embedding — Variant Lab (#2009 / #2196) is a separate surface (its own redesign ticket).
